## 研究任务与主张边界

同一ROI内，利用CERRA历史风速与遥感地表特征，预测已知目标网格的未来10m风速。100个point_id对应98个唯一格。原研究覆盖3/6/12/24h；当前遥感研究聚焦3h。属于滚动起报回溯预测，目标也是CERRA，不等于站点、轮毂高度、风功率或业务实时验证。

## 已完成证据

| 阶段 | 实际完成 | 主要结果 |
|---|---|---|
| 原时间/空间实验 | 旧V1 84、夏季V2 80、固定四窗口320次，共484次 | A01的3h相对T01 RMSE改善四窗口约4.51/4.54/2.94/2.68%；秋季区间跨零；冬季相对Persistence的所有空间组/提前量区间均跨零 |
| P0/P0b | 320份旧预测审计、368份归档展示 | 数据来源、映射、预测网格、固定案例及架构可追溯 |
| P1强基线 | 48个选定配置、144次候选拟合 | Ridge与histogram gradient boosting重现春夏3h空间收益，秋季不稳；不能称作LightGBM |
| P1c方向 | 12次拟合及42条日期区间 | 三折等权验证收益−1.70%，按既定规则关闭方向，测试探索结果仍保留 |
| P2遥感 | 16瓦片、98格14维、100点映射、完整QA | WorldCover11类比例＋DSM均值/SD/坡度；有效覆盖率近100% |
| P3融合 | 36次，4组×3窗口×3种子 | 共享融合头、有/无RS同结构；空间输入仍有增益，遥感增量小且随窗口变化 |
| P3日期分析 | 912912，192区间、4032逐日贡献 | 夏季空间RS RMSE/MAE区间为正；春跨零；秋MAE区间为负 |

P3空间RS的RMSE/MAE配对改善：春+0.226%/+0.040%，夏+0.900%/+1.176%，秋−0.851%/−1.269%。夏22/28天平方误差下降，剔除三个最大正贡献日后仍有约0.61% RMSE改善；该剔除是事后敏感性分析，估计量与逐seed百分比均值不同。

当前最强结论是动态空间信息有重复出现的预测价值，且并非LSTM独有。静态遥感已得到独立、受控评价，但尚无跨窗口普遍增益、物理机制或未见网格迁移的证据。数据QA通过不等于预测价值已经证实。
